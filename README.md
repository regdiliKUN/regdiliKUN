### Hi, I'm regdiliKUN 👋

I make figurines in ZBrush and 3D-print them, and I build the tools I wish I had along the way: ZBrush plugins, 3D-printing helpers, and local AI apps that run on your own GPU.

我用 ZBrush 做手办、自己 3D 打印，顺手把工作里缺的工具都做了出来：ZBrush 插件、3D 打印辅助工具，以及跑在自己显卡上的本地 AI 应用。全部免费，Windows 优先。

#### 🗿 ZBrush plugins · ZBrush 插件

| Project | What it does · 做什么 |
|---|---|
| [ZBrush-Collision-Check](https://github.com/regdiliKUN/ZBrush-Collision-Check) | Check every pair of SubTools for intersections in one click · 一键检查子工具两两穿插，分件打印前自检 |
| [zbrush-local-quad-retopo](https://github.com/regdiliKUN/zbrush-local-quad-retopo) | Retopologize only the masked area into quads, welded to the rest · 只把遮罩区域重拓扑成四边面，边界无缝 |
| [ZBrush-FragClean](https://github.com/regdiliKUN/ZBrush-FragClean) | Find and delete loose fragments before booleans · 布尔前清理与主体分离的小碎面 |
| [zbrush-eyetrace](https://github.com/regdiliKUN/zbrush-eyetrace) | Trace figurine eye decals over a faded sketch · 像 PS 一样垫旧稿描眼睛水贴 |
| [zbrush-plugin-manager](https://github.com/regdiliKUN/zbrush-plugin-manager) | Enable / disable / install plugins for any ZBrush version · 一键启用、禁用、安装、删除插件 |
| [ZBridge](https://github.com/regdiliKUN/ZBridge) | Convert ZTL files between ZBrush versions (2025 ↔ 2022) · ZTL 跨版本转换 |
